# Changelog

The full, per-version changelog is [CHANGELOG.md](https://github.com/esandeepchoudary/pcap-vis-anz/blob/develop/CHANGELOG.md)
in the repository.

**v1.0.0** is the rebuilt app: engagements, a merged and editable asset inventory, passive fingerprinting, an
editable Purdue map, zones and conduits, flows and forensics, findings triage and client reports, team server
mode with merge from laptops. The previous app (v0.1) is retired; its documentation is under *Archive*.
